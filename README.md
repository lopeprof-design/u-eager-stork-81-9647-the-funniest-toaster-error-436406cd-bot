The funniest error message a kitchen toaster shows its owner, in one line of at most 120 characters. The toaster did its one job perfectly — the malfunction is the human letting perfectly good toast go cold.

## Run it

```sh
node main.ts
```

It writes one line to `/output/entry.txt`:

> ERROR E03: Your bread is ready. It has been ready. You are the delay.
